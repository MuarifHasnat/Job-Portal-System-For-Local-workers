# job-portal-system-for-local-worker-
A PHP & MySQL-based Job Portal System with secure authentication, admin dashboard, and user/worker management.  
Developed as part of academic coursework in Computer Science & Engineering.

## 📂 Project Structure

## 🚀 Features

- Secure authentication (login, register, session management)
- Admin dashboard for managing users, workers, and jobs
- Job postings, bookings, and request handling
- Worker profiles with reviews and ratings
- Notification system for users and admins
- Modular folder structure for scalability

## 🛠️ Technologies Used
- **Backend:** PHP (XAMPP environment)
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Server:** Apache (via XAMPP)
